# 视频沉浸布局与画面适配设计

日期：2026-08-20  
目标环境：红果免费短剧 `7.3.3.18`，Android 16

## 背景

当前实现把三个独立行为耦合在一起：隐藏系统状态栏、回收底部选集栏占位、修改播放器缩放模式。窗口或内容区尺寸变化会触发宿主重新计算视频布局，造成状态栏区域变黑；隐藏底部选集栏只隐藏视图而未可靠回收布局占位，留下黑块；直接暴露播放器内部 `0/1/2/3` 模式也无法让用户理解实际效果。

## 目标

1. 隐藏状态栏只移除时间、电量等系统元素，不改变宿主原有视频画面位置、尺寸和缩放方式。
2. 原本绘制在状态栏背后的画面，在隐藏状态栏后继续显示，不出现新增黑块。
3. 隐藏底部选集栏时回收对应布局占位，但不隐式改变视频缩放方式。
4. 提供独立且语义明确的画面适配选项：保持原画面或裁剪铺满。
5. 长按切换界面精简时，由用户决定是否同时隐藏选集栏。
6. 所有修改可逆，关闭开关后恢复宿主原始状态。

## 非目标

- 不通过拉伸视频消除黑边。
- 不保证“保持原画面”在所有宽高比下都没有播放器自身产生的留边。
- 不继续向用户暴露播放器内部整数枚举。

## 设计

### 1. 状态栏隐藏与视频缩放解耦

Android 16 下使用 `WindowInsetsController` 控制状态栏可见性，同时保持宿主既有的 Edge-to-Edge 内容布局。

隐藏状态栏时：

- 不把宿主的状态栏高度查询结果篡改为 `0`；
- 不额外设置会改变旧式内容区测量的 `FLAG_FULLSCREEN`；
- 不因状态栏开关调用宿主播放器的布局重置方法；
- 保留宿主原有 `LAYOUT_FULLSCREEN`、cutout 与 decor fitting 行为；
- 只恢复模块实际修改过的窗口状态。

结果应是状态栏前景消失，背后的原视频像素保持不变。

### 2. 画面适配选项

将当前 `模式 0/1/2/3` 替换为：

- **保持原画面（默认）**：不覆盖播放器缩放模式，完整跟随宿主行为。
- **裁剪铺满**：对已确认的播放器渲染入口应用等比中心裁剪，消除由画面宽高比产生的黑边；允许裁掉部分上下或左右内容。

状态栏隐藏修复始终生效，不依赖画面适配选项。“保持原画面”表示不处理缩放，不表示放任状态栏区域变黑。

### 3. 底部选集栏与占位回收

针对 `7.3.3.18` 的实际底部选集容器进行识别：

- 隐藏整条选集容器时使用可回收布局空间的方式，而不是仅设为 `INVISIBLE`；
- 记录并清除仅属于该选集栏的底部 margin、constraint 或固定高度占位；
- 不把整个视频树无条件改为 `MATCH_PARENT`；
- 不在该步骤修改播放器缩放模式；
- 恢复选集时按快照还原 visibility、尺寸、margin、constraint 和 padding。

### 4. 长按行为选项

新增布尔设置：**长按隐藏时同时隐藏选集**。

- 默认开启，以保持现有长按行为兼容；
- 开启：长按切换“隐藏控件、选集、进度条”；
- 关闭：长按只切换“隐藏控件、进度条”，保留用户当前的选集开关状态；
- 设置面板中的独立“选集相关功能”开关仍然可以手动控制选集栏；
- 长按恢复时只恢复本次长按实际接管的项目，避免覆盖用户手动配置。

### 5. 状态记录与恢复

分别保存以下状态，避免交叉覆盖：

- 模块修改过的 Activity 状态栏状态；
- 选集容器原始 visibility 与布局参数；
- 画面适配偏好；
- 长按前的控件、进度条和选集配置。

弱引用缓存用于避免持有已销毁 Activity/View。所有 UI 修改在主线程执行。

## 用户界面

设置面板调整为：

- `画面适配`
  - `保持原画面（内容优先）`
  - `裁剪铺满（无黑边，可能裁剪）`
- `长按顶部切换界面精简`
- `长按隐藏时同时隐藏选集`

移除 `模式 0/1/2/3` 文案。

## 验收标准

1. 同一视频暂停在同一帧，隐藏状态栏前后，视频在状态栏背后的画面位置不变且不变黑。
2. “保持原画面”下不强制裁剪，视频内容范围与宿主原生播放一致。
3. “裁剪铺满”下没有由视频宽高比造成的上下/左右黑边，画面不拉伸。
4. 隐藏底部选集后不残留固定高度黑块；恢复后布局与原生一致。
5. 关闭“长按隐藏时同时隐藏选集”后，长按不会改变选集栏的显示状态。
6. Android 16 全屏、手势导航、挖孔屏以及进入/退出多窗口后均能恢复正确状态。
7. 关闭模块总开关后，宿主窗口与所有已记录布局参数完整恢复。

## 验证策略

- 构建与静态检查：运行 Gradle debug 构建。
- 日志验证：记录状态栏操作、选集占位回收、画面模式应用及恢复次数。
- 设备验证：在红果 `7.3.3.18`、Android 16 上分别测试竖屏短剧、不同宽高比素材、暂停/继续、切集、长按切换、前后台切换及多窗口往返。
- 对比验证：隐藏状态栏前后截取同一帧，比较视频内容边界；隐藏选集前后比较渲染容器边界与底部空白区域。
